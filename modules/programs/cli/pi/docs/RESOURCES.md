# Resources and Settings

## Global settings

`settings/global.json` controls default provider/model, token settings, compaction, global packages, theme, and powerline.

## Project settings

Project settings are generated by merging global settings with an overlay:

- `settings/study.overlay.json`
- `settings/study-tutor.overlay.json`
- `settings/work.overlay.json`

Project-local resource paths use Pi's project settings convention and are relative to `.pi`, so they must be:

```json
"prompts": ["prompts"],
"skills": ["skills"]
```

not `.pi/prompts` or `.pi/skills`.

## Pinned packages

Global security/control packages are pinned in `settings/global.json`. See `docs/PACKAGE_UPDATES.md` and run `pi-admin compat` before changing versions.

Do not use `pi install`, `pi remove`, `pi uninstall`, or `pi config` as the durable source of truth for this setup.

## Package/runtime boundary

Do **not** set `PI_PACKAGE_DIR` in wrappers.

`NPM_CONFIG_PREFIX=~/.pi/agent/npm` controls where `pi-npm` installs global npm packages. `PI_PACKAGE_DIR` is a Pi runtime package directory override and can break internal asset lookup if pointed at the npm cache.

See `docs/package-runtime-boundary.md`.

## Study memory

Study memory is Markdown-first:

- `MEMORY.md` — reviewed learner memory.
- `vault/10-topics/` — durable topic notes.
- `vault/20-daily/` — append-only daily logs.
- `vault/30-summaries/` — reviewed summaries.

The default `pi-study` profile does not require `qmd`, Bun, `pi-memory`, or Obsidian extensions.

## Conversation memory

Global conversation and personal interaction memory lives in three places:

- `resources/global/AGENTS.md` — always-active behavior and interaction rules.
- `resources/global/MEMORY.md` — reviewed, human-approved personal memory.
- `pi-hermes-memory` — automatic soft recall, pinned in `settings/global.json` when enabled.

See `docs/CONVERSATION_AND_MEMORY.md`.
