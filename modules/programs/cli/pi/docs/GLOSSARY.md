# Glossary

- **Source-managed**: durable configuration in the NixOS repo.
- **Runtime**: generated or user-owned files under `~/.pi/agent`, `~/Learning`, or work projects.
- **Managed file**: overwritten from source by sync scripts.
- **Seed file**: copied only if missing, then user-owned.
- **Policy**: `pi-permission-system` JSONC rule file.
- **Wrapper**: command such as `pi-nixos` or `pi-study` that sets profile-specific environment and launch behavior.
- **Wiki-first**: use `docs/INDEX.md` and `docs/LOOKUP.json` before broad search.
