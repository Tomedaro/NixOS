## Do not do next

- ❌ **Do not patch SDD subagents to add memory tools yet.** Wait for upstream Gentle AI issue #602 or design project-local overrides through `.pi/agents/`. Parent-only orchestration is already documented and sufficient.
- ❌ **Do not Nix-package every npm Pi extension.** It's expensive, brittle, and not needed while pinned npm specs + compat enforcement work. Evaluate lockfile or selective Nix-packaging for critical extensions first.
- ❌ **Do not split `scripts.nix` / `wrappers.nix` before stronger tests exist.** Source-check, compat enforcement, and permission regression tests should be in place first to catch regressions from refactoring.
- ❌ **Do not treat `pi-readonly` / `pi-cautious` as a real sandbox.** It is policy-backed convenience only. Real isolation requires bubblewrap/systemd namespaces and is tracked in P8.
- ❌ **Do not automate `nixos-rebuild switch` from SDD.** Keep manual approval.
- ❌ **Do not move mutable runtime settings (`settings.json`, `mcp.json`) to `home.file` yet.** Keep them under pi-admin sync until activation integration (P4) is stable.
