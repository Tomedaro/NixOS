# Pi Module — Structured Improvement Plan

Generated by: smarter LLM (Phase 2, after research brief)
Source: analysis of the Pi NixOS module tarball
Date: 2026-06-08

---

## Guiding principle

Keep current user-facing commands working, improve underneath in order:

```
verify → fail closed → expose options → reduce runtime drift → sandbox experiments → deeper supply-chain work
```

## Phase 1 — Security hardening quick wins

### 1.1 Make all policy-backed profiles check permission extension presence
- Move check into wrapperPrelude
- Verify: policy exists, pi-permission-system installed, version matches pin
- Refuse launch on failure, escape hatch: pi-raw
- Files: wrappers.nix, scripts.nix, docs

### 1.2 Add version verification helper
- Shared shell helper to extract pinned versions from settings/global.json
- Reuse in: compat-check, wrapperPrelude, pi-admin status
- Files: scripts.nix, wrappers.nix

### 1.3 Add pi-cautious as primary name
- New wrapper, same implementation as pi-readonly
- Keep pi-readonly and pi-safe as aliases
- Update docs to prefer pi-cautious / PI_PROFILE=cautious
- Files: wrappers.nix, home-module.nix, docs

### 1.4 Add friction to pi-trusted
- Require PI_TRUSTED_ACK=1 to proceed
- Print warning without it
- Files: wrappers.nix, docs

### 1.5 Add launch metadata stamping
- Write to ~/.pi/agent/sessions/<profile>/last-launch.json + launches.jsonl
- Metadata only: profile, timestamp, cwd, gitRoot, policy hash, versions
- Files: wrappers.nix, docs

## Dependency map (simplified)

```
0.x (validation) → supports everything
1.x (security) → blocks claiming profiles are safe
2.x (introspection) → supports user verification
3.x (HM module) → before serious reusable module work
4.x (declarative) → after drift/source checks reliable
5.x (MCP pinning) → security priority
6.x (supply-chain) → after version helper
7.x (refactors) → after validation/introspection
8.x (sandbox) → can start after 1.x stable
9.x (docs) → ongoing
```

## Do not do

- Full rewrite before validation
- Move study/work files to Home Manager
- Convert policies from JSONC to Nix attrsets
- Make shell deny patterns complete
- Remove pi-trusted
- Replace pi-readonly with bubblewrap immediately
- Package all npm extensions with Nix immediately
- Move to XDG paths now
- Automate provider metadata updates from web
