# Work Session Skill

Use when Daniil asks to work on a project through `pi-work`.

## Workflow

1. Read project instructions if present.
2. Identify the smallest relevant files.
3. Avoid broad scans unless necessary.
4. Prefer small, reviewable diffs.
5. Explain validation commands.
6. Do not access unrelated personal directories or secrets.
