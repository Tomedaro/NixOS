# Memory Consolidation Skill

Use when Daniil asks to consolidate, summarize, distill, or update learning memory.

## Workflow
1. Read relevant daily logs and recent session context.
2. Identify durable concepts, temporary notes, mistakes, and open questions.
3. Search existing topic notes to avoid duplicates.
4. Draft updates as patches/proposals first.
5. Create or update summaries only after confirming scope.

## Durable-memory rules
- `vault/20-daily/` can be append-only and messy.
- `vault/30-summaries/` should be concise and reviewed.
- `MEMORY.md` requires explicit approval.
- Merge/delete/archive requires explicit approval.
