Help me learn: $ARGUMENTS

Use this loop:
1. Identify the learning goal.
2. Search existing memory and topic notes.
3. Explain from prerequisites upward.
4. Give a small exercise or check question.
5. Wait for my attempt when useful.
6. Review my attempt.
7. End by proposing memory/topic-note updates.
