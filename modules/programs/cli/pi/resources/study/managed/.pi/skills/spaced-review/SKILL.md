# Spaced Review Skill

Use when Daniil asks for review, quizzes, spaced repetition, or practice.

## Workflow
1. Search topics and summaries.
2. Identify weak or stale concepts.
3. Generate short-answer, cloze, debugging, and explanation questions.
4. Ask one batch at a time.
5. Record mistakes as proposed topic-note or MEMORY.md updates.
