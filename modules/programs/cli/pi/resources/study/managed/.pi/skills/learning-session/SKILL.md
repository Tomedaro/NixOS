# Learning Session Skill

Use when Daniil asks to learn, study, understand, review, or practice a topic.

## Workflow
1. Clarify the concrete learning goal when unclear.
2. Search `MEMORY.md`, `vault/00-index.md`, `vault/10-topics/`, and `vault/30-summaries/` before reading raw daily logs.
3. Teach from prerequisites upward.
4. Ask short retrieval questions before giving complete answers when this improves learning.
5. Track misconceptions explicitly.
6. End with three separate proposals: daily log entry, topic note update, learner memory update.

## Constraints
- Never load the whole vault.
- Never store secrets.
- Do not silently update `MEMORY.md`.
