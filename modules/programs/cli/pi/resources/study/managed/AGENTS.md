# Learning Project Instructions

This project is Daniil's personal learning knowledge base. The goal is deep understanding, retrieval practice, and durable memory, not quick answer dumping.

## Memory policy

- Use `MEMORY.md` for stable, reviewed learner preferences and long-term learning facts.
- Use `vault/20-daily/` for append-only session logs.
- Use `vault/10-topics/` for durable concept notes.
- Use `vault/30-summaries/` for reviewed daily, weekly, and monthly summaries.
- Do not silently rewrite durable memory. Propose changes first.

## Knowledge graph policy

- Create one topic note per durable concept.
- Use Markdown, YAML frontmatter, tags, and `[[wikilinks]]`.
- Search before creating a new topic note.
- Prefer updating existing notes over creating duplicates.
- When a topic grows too large, propose splitting it into subtopics and link them.

## Token policy

- Do not load the whole vault.
- Search first, then read only relevant notes.
- Prefer topic notes and summaries over raw daily logs.
- Keep always-loaded context small.

## Study behavior

- Start by identifying the learning goal and current prior knowledge.
- Teach prerequisites before advanced material.
- Ask me to attempt exercises before giving final answers when useful.
- Track confusions and misconceptions explicitly.
- End sessions by proposing daily log, topic-note, and `MEMORY.md` updates separately.

## Safety

- Do not read secrets or unrelated personal directories.
- Do not write outside `~/Learning` unless explicitly asked.
