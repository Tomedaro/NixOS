# Agent Memory

## Core idea

Use Markdown as canonical memory, search selectively, and require review before durable updates.

## Layers

- `AGENTS.md`: behavior rules.
- `MEMORY.md`: reviewed learner profile.
- `10-topics/`: durable topic graph.
- `20-daily/`: append-only raw notes.
- `30-summaries/`: reviewed summaries.

## Rule

Do not auto-inject or rewrite the whole brain. Search and load only relevant notes.
