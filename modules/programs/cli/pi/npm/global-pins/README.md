# Pi global npm pins lockfile

This directory contains a source-controlled npm root for the Pi module's repo-owned global npm extension pins.

It is generated from:

```text
modules/programs/cli/pi/settings/global.json -> packages[]
```

The files here cover only the globally declared package pins owned by this repo. They do not represent the full runtime npm project under:

```text
~/.pi/agent/npm
```

The runtime npm project is generated by Pi's extension manager and may contain additional root dependencies from profile overlays or user/Pi/legacy runtime state.

As of P6C, the expected ownership split is:

* global source-owned pins: 18 packages from `settings/global.json`
* study-tutor profile extras: `@majorgilles/pi-learning-tutor`, `keating`, `teach-me`
* user/Pi/legacy runtime extras: `context-mode`, `pi-memory`, `pi-obsidian`, `pi-studio`

This lockfile is currently an audit/comparison artifact only. It does not change runtime installation behavior. Pi still manages runtime extension installation under `~/.pi/agent/npm`.

Do not treat this lockfile as proof that the full runtime npm tree is source-reproducible. It proves only the locked tree for repo-owned global pins.

Future `pi-admin npm-check` work should compare:

* `settings/global.json` pins
* this source package root
* this source lockfile
* runtime installed versions
* runtime `~/.pi/agent/npm/package-lock.json`

Runtime install changes such as `npm ci`, `ignore-scripts=true`, or Nix packaging are deferred.
